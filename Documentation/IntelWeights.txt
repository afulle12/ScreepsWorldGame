================================================================================
                         ROOM INTEL SCORING SPEC V2
================================================================================

PURPOSE
--------------------------------------------------------------------------------
Room intel separates room capability into:

  Defense          Ability to resist attacks
  Offense          Combat and offensive readiness
  Economy          Resources and economic systems
  Infrastructure   Controller, spawning, logistics, and utility structures
  Operations       Observed execution efficiency
  Composite        Attacker-oriented overall score

Operations is reported separately and is not included in the composite score.

================================================================================
                         SCORE OBJECT
================================================================================

scores: {
    defense,
    offense,
    economy,
    infrastructure,
    operations,
    composite,

    // Backward-compatible aliases
    overall,       // same value as composite
    economic,      // same value as economy
    military,      // average of defense and offense
    dualPurpose,   // same value as infrastructure

    confidence     // 0.0 to 1.0
}

All dimension scores are clamped to 0-100.

================================================================================
                         COMPOSITE WEIGHTS
================================================================================

FULL INTEL
--------------------------------------------------------------------------------
Defense:          30%
Offense:          20%
Economy:          20%
Infrastructure:   20%
Operations:       reported separately, excluded from composite

Active composite weights total 90%, so the active dimensions are normalized:

  composite =
    (defense * 0.30
   + offense * 0.20
   + economy * 0.20
   + infrastructure * 0.20) / 0.90

FAST INTEL / PLAYER ANALYSIS
--------------------------------------------------------------------------------
Fast analysis uses the documented three-category blend:

Economy:          25%
Military:         30%
Infrastructure:   45%

  military = (defense + offense) / 2

  composite =
    economy * 0.25
  + military * 0.30
  + infrastructure * 0.45

Operations is null for fast analysis.

PATHFINDING
--------------------------------------------------------------------------------
Entrance points are sampled every 5 tiles along all four room edges.

Terrain wall tiles are excluded from entrance candidates.

Walls and ramparts are treated as impassable.

A path is considered exposed when PathFinder finds a complete path from an
entrance to the target.

NUKER CHARGE
--------------------------------------------------------------------------------
Energy fraction:
  energy stored / energy capacity

Ghodium fraction:
  ghodium stored / ghodium capacity

Bottleneck charge fraction:
  min(energy fraction, ghodium fraction)

Nuker charge score:
  bottleneck charge fraction * 6

Nuker ready:
  - True when both resources are full.
  - Cooldown does not change the intel score.

Nuker charging:
  - True when either resource is present and the nuker is not full.

COMBAT CREEPS
--------------------------------------------------------------------------------
A military creep has at least one:

  ATTACK
  RANGED_ATTACK
  HEAL

Military creep score:
  min(10, military creep count * 2)

Combat parts and military creep count are reported separately.

BOOSTS
--------------------------------------------------------------------------------
Combat stockpile includes:

  Attack:
    UH, UH2O, XUH2O

  Ranged attack:
    KO, KHO2, XKHO2

  Heal:
    LO, LHO2, XLHO2

T3 weighting:
  - T1 and T2 amounts count at 1x.
  - T3 amounts count at 3x.
  - This is an initial calibration heuristic.

Weighted stockpile score:
  min(weighted amount / 30,000, 1) * 15

Boosted-creep and stockpile measurements only include creeps and resources
belonging to the room controller owner.

================================================================================
                              CONFIDENCE
================================================================================

Confidence describes freshness of the observation, not room strength.

Current visible room:             1.0
Registry observation age <=100:   1.0
Age 100-1,000 ticks:              Linear decay from 1.0 to 0.9
Age 1,000-5,000 ticks:            Linear decay from 0.9 to 0.0
Age >5,000 ticks:                 0.0
No observation metadata:          0.0

Unknown intel is represented as confidence 0.0.

Confidence does not reduce the strength score. It indicates how much trust
should be placed in the score.

================================================================================
                       PLAYER ANALYSIS BEHAVIOR
================================================================================

Player analysis uses silent fast intel for each observed room.

Room classification thresholds:

  STRONG:   composite >= 70
  AVERAGE:  composite >= 40 and < 70
  WEAK:     composite < 40

Player reports include:

  Average composite
  Average defense
  Average offense
  Average economy
  Average infrastructure
  Per-room split scores
  Room confidence
  Resource totals
  Tower and spawn totals
  Nuker and strike information
  Defense-based attack recommendations
